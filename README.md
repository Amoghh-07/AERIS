# AERIS — AI-Enabled Rescue & Incident Support

AERIS is an AI-assisted disaster-response command and coordination platform designed to support emergency teams during disaster situations.

## 🚨 Features

- Multi-drone command center
- Disaster-zone visualization
- Drone monitoring and telemetry
- Victim detection and triage
- Priority and emergency escalation
- Animal rescue support
- Telemedicine workflow
- Missing-person identification
- Face matching workflow
- Emergency communication
- AI-assisted situation analysis
- Rescue mission monitoring

## 🛠️ Technology

- React
- TypeScript
- Vite
- Node.js
- Express
- Google Gemini API
